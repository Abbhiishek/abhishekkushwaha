## VaaniFlow Distinctness Check

- **Reader problem:** dictate into arbitrary Windows applications without changing workspaces.
- **Thesis:** speech recognition is one stage in a desktop automation and text-delivery pipeline.
- **Architecture:** Electron privilege boundaries, audio chunking, provider calls, deterministic and probabilistic processing, clipboard/Win32 injection, and local persistence.
- **Examples:** protected snippet tokens, dictionary hints plus replacements, terminal paste behavior, stale-session generation checks, and failed-audio recovery.
- **Tradeoffs:** local-first versus offline, sequential context versus parallel throughput, generic paste versus app adapters, editable credentials versus native secret storage.
- **Viewpoint:** an honest architecture review of a recently built open repository without invented usage metrics or experiences.
- **Takeaway:** end-to-end delivery reliability matters more than transcript accuracy in isolation.
- **Nearest existing article:** `voice-agent-ai-interviews.md`; it focuses on conversational turn-taking and TTS latency, while VaaniFlow focuses on one-way Windows dictation, personalization, insertion, privacy boundaries, and recoverability.
